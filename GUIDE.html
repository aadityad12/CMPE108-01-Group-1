Minimum defensible project: a shared CoMER base; a few genuinely unseen writers; fixed tests; all three adaptation methods; a sample-count curve; a general-recognition check; an error analysis; and a working demo. Three writers support an exploratory study, not a broad claim about all students. Approximately twenty eligible public writers is an expansion target, subject to a data audit.

2. Learn the small set of concepts you need

TermMeaning in your project
Image and labelAn image of an expression paired with its correct LaTeX, such as x ^ { 2 } + 1.
Token / vocabularyA token is one output unit: x, ^, {, or \frac. The vocabulary lists units the model can output.
EncoderConverts the image into numerical visual features. CoMER uses a DenseNet encoder.
DecoderPredicts LaTeX tokens from those features. CoMER uses a Transformer decoder with coverage information [3].
Pretrained weights / checkpointParameters learned previously; a saved model file containing those parameters.
Fine-tuningContinue learning from an existing checkpoint using your data.
LoRA adapterSmall trainable matrices that modify selected frozen weight matrices [5].
Training / validation / testTraining updates weights. Validation selects settings/checkpoints. Test measures a final model after choices are fixed.
Learning rateHow large each parameter update is. Too large can damage pretrained behavior.
Batch / step / epochA batch is the examples used for one update; a step is one update; an epoch is one pass through a dataset. This starter samples batches and controls update steps explicitly.
SeedA number controlling random choices. Repeated seeds estimate sensitivity to initialization and sample ordering.
Overfitting / forgettingOverfitting is learning training examples without improving new ones. Forgetting is reduced general recognition after adaptation.
Slurm / partition / GPU allocationThe HPC scheduler; a resource queue; and a reservation allowing your program to use a GPU.

Learn enough Python to understand lists, dictionaries, functions, loops, imports, file paths, and with blocks. Then learn tensors, model.train(), model.eval(), loss.backward(), and optimizer.step(). You can learn these while running the pilot; you do not need to master all of deep learning first.

3. Turn the abstract into testable questions

  1. Personalization: does adapting to writer w improve recognition on new expressions from that writer?
  2. Sample efficiency: how does the improvement change at 10, 25, 50, and 100 labels?
  3. Method: how do full, decoder, and LoRA tuning compare in accuracy, trainable parameters, storage, and time?
  4. Generalization: what happens on a separate general test set while the personalized model is active?
  5. Camera robustness: does shared phone-domain training help before writer personalization?

Four corrections to make before promising the final experiment:

  • CROHME 2023 combines several sources and modalities [6,7]. Verify writer metadata and usable per-writer counts in the exact files you receive. Do not infer people from arbitrary filename prefixes.
  • Writer-disjoint support/test construction alone does not prove writers were unseen by the released pretrained checkpoint. Newly collected team handwriting gives you the clearest provenance. For public writers, compare documented identities against pretraining sources; if identities cannot be reconciled, describe pretraining writer overlap as unknown.
  • The checkpoint filename's 0.6365 is a legacy validation statistic. The repository itself says its training-validation metric is not the official benchmark evaluator [8]. Measure your own baseline.
  • HME100K expands beyond the CROHME vocabulary. The starter audits this and allows domain training on the supported-token subset. Report the retained count and exclusions. Training on the entire vocabulary would require an additional embedding/output-vocabulary migration.

Recommended fixed protocol: reserve at least 150 distinct formulas per evaluation writer: 100 for a support pool, and 50 for a test set. Draw nested support prefixes of sizes 10, 25, 50, and 100. All methods and all seeds use the same prefixes and the same test set. Extra captures of a formula must not be counted as independent labels or split across support and test.

Tune learning rate, update count, augmentation, and LoRA rank using separate development writers. Once fixed, evaluation writers supply only their stated support labels and an untouched test. A per-writer validation set would consume additional labels; do not quietly describe “10 labels” if you also use 20 labeled validation images. If only three team writers exist, use separate public development writers where possible, recruit another development writer, or label the study exploratory if settings were chosen using a team writer.

Keep formula families and acquisition sessions documented. The starter prevents exact normalized formulas from crossing each writer's support/test boundary. It cannot automatically detect algebraically equivalent rewrites, near-duplicate camera frames, or unseen writer identity errors. Inspect contact sheets and metadata for those cases. Stronger splits can hold out template families or whole acquisition sessions.

6. Make the first prediction

python -m wlm.predict image \
  --checkpoint checkpoints/base.pt \
  --image third_party/CoMER/example/UN19_1041_em_595.bmp \
  --polarity light_on_dark --device cpu

The preparation run produced:

x ^ { 2 } = \sum \limits _ { a = 1 } ^ { 3 } x _ { a } ^ { 2 }

For a phone photo, crop tightly around one complete expression, keep all fraction bars and superscripts, and use:

python -m wlm.predict image --checkpoint checkpoints/base.pt \
  --image data/my_expression.jpg --polarity dark_on_light --device cuda

Why polarity matters: the bundled images have white ink on black. A normal photograph has dark ink on light paper. The code uses explicit manifest polarity to convert them to the expected representation. It keeps the aspect ratio, limits dimensions to 1024 × 256, and pads very small images. It never stretches a fraction to a square.

7. Obtain, label, and audit the data

One shared format: every dataset becomes JSON Lines: one JSON object per expression. Image paths can be absolute or relative to the manifest. The example file illustrates syntax; replace its placeholder image paths.

{"id":"team01-001","image":"images/team01-001.jpg","latex":"x ^ { 2 } + 1","writer_id":"team01","dataset":"team","official_split":"new","polarity":"dark_on_light"}

Backslashes in JSON strings need escaping: LaTeX \frac is written "\\frac". Do not include rendered dollar delimiters in the label; the tokenizer tolerates a paired outer delimiter but labels should remain consistent. The label describes what is written, even if the mathematical equation is false.

Team handwriting: start here

  1. Choose prompt expressions with short arithmetic, letters, fractions, exponents, subscripts, radicals, sums, and a range of lengths. Check tokens against third_party/CoMER/comer/datamodule/dictionary.txt.
  2. Start with a 10-expression pilot. For final curves, aim for 150–200 distinct labeled formulas per evaluation writer. At least 150 are needed for the default 100-support/50-test protocol.
  3. Write each expression naturally. Photograph in at least two sessions; record phone, lighting, date/session, writer ID, and formula ID. If all writers use one camera in one condition, describe that limitation.
  4. Crop each expression. Have one teammate label and another verify every LaTeX string against the photo. Keep a correction log. Avoid color markup and complicated macros outside the vocabulary.
  5. Write data/team.jsonl. IDs such as team01 are enough; real names are unnecessary. Retain the originals privately and agree on permission to use the handwriting in the report/demo.

CROHME 2023: download CROHME23.zip from the official record and inspect its README, nested archives, modalities, and metadata. Use the provided offline images when available. The starter joins image stems to InkML labels; it deliberately rejects ambiguous matches. Run it on one actual source/split directory at a time, and give globally distinct dataset/site names where writer IDs may be local:

python -m wlm.prepare crohme \
  --inkml data/raw/CROHME/ACTUAL_INKML_DIRECTORY \
  --images data/raw/CROHME/ACTUAL_IMAGE_DIRECTORY \
  --dataset CROHME23_SITE_NAME --split train \
  --polarity dark_on_light --output data/crohme_site.jsonl
# If writer identities are in a separate documented mapping:
# add --writer-map data/verified_writer_map.csv

Set polarity by viewing actual images. The importer reads top-level truth/LaTeX and writer/writerID annotations when present. A writer CSV maps the relative InkML path or stem to the verified person. See examples/writer_map.csv. It preserves unknown IDs as null. It does not render bare traces, invent writer IDs, or assume every subset has labels. If you have only InkML, use the organizers' CROHMElib referenced in the record, or obtain matching offline images before importing [7].

HME100K: request/download through the official site linked from its repository. Do not delay the team pilot while access is pending. The repository describes train/test image folders and label text files [10]. After access:

python -m wlm.prepare hme100k \
  --labels data/raw/HME100K/train/train_labels.txt \
  --images data/raw/HME100K/train/train_images --split train \
  --output data/hme_train_raw.jsonl
python -m wlm.prepare audit --manifest data/hme_train_raw.jsonl \
  --output data/hme_train_audit.json --filtered data/hme_train_supported.jsonl
python -m wlm.prepare domain-split --manifest data/hme_train_supported.jsonl \
  --output data/domain

The domain split groups identical tokenized formulas and takes validation only from the official training partition. HME100K writer IDs are not invented. Without documented identities, neither writer-disjoint internal splitting nor HME-to-CROHME writer disjointness is established; disclose that. Keep the official HME100K test partition out of model selection.

Audit every new manifest:

python -m wlm.prepare audit --manifest data/team.jsonl \
  --output data/team_audit.json

The audit reports writer counts, unknown tokens, duplicate image bytes/IDs, missing or unreadable images, and labels beyond the 198-token training limit. Use --filtered only for a declared training subset. Do not silently filter test images based on model vocabulary. Test decoding retains OOV labels, so limitations remain visible. The tokenizer treats braces and structural commands as tokens; it does not prove that two different LaTeX strings are semantically equivalent.

Keep a dataset log: source URL, download date, archive hash, permitted usage, image/label counts, modalities, writer coverage, and exclusions. Recheck the downloaded CROHME license and obtain HME100K usage terms; the pinned CoMER tree has no license file. This starter excludes their source/data/weights from redistribution and does not treat coursework as an explicit usage grant.

9. Add shared phone-domain training after the pilot works

Purpose: teach one shared model to handle camera conditions before tailoring separate copies to writers. This is distinct from personalization. Keep a frozen copy of both the original and phone-adapted bases.

python -m wlm.train --base checkpoints/base.pt \
  --manifest data/domain/train.jsonl --val data/domain/val.jsonl \
  --method full --lr 0.00001 --steps 2000 --batch-size 4 \
  --augment --output runs/domain --device cuda

This is an initial budget, not a recommended final convergence claim. At batch size 4, 2,000 updates sample about 8,000 image presentations, much less than one full pass through approximately 74,000 examples. Inspect the validation-loss curve and recognition on development data, then choose a sufficient schedule. The best validation-loss checkpoint is runs/domain/best.pt; model.pt is the latest resumable state. Selection uses validation loss in this starter; test recognition remains held out.

Training-only augmentations include mild blur, an illumination gradient, and small perspective changes. They are intentionally modest starting settings. Visually inspect a few transformed images so minus signs and radical bars remain readable. No augmentation is applied during test decoding. The exact augmentation policy is part of the experiment, not an assumed universal improvement.

Compare original CoMER versus the phone-adapted base on the same development and final test data. If HME100K remains inaccessible, continue the core writer study and optionally use augmentation on an approved writer-disjoint public training pool. State the resulting scope accurately; synthetic distortions are not evidence that HME100K training occurred.

10. Run the three personalization methods

Use the same base, support labels, decoding settings, and test images for every method. The following defaults are starting points to select using development writers:

MethodUpdatesInitial learning rateWhat learns
full2000.00001All model parameters; BatchNorm running statistics stay frozen.
decoder2000.00005Decoder parameters. Encoder weights, running statistics, and encoder dropout stay fixed.
lora2000.001Rank-8 LoRA updates in six decoder feed-forward layers; 61,440 trainable parameters.

The LoRA targets are decoder.model.layers.{0,1,2}.linear{1,2}. CoMER uses custom attention projection tensors; a generic Hugging Face q_proj/v_proj recipe would not find those modules. This implementation uses clearly declared FFN LoRA, not attention Q/V LoRA. It saves only adapter matrices plus resumable training state and checks the exact base hash on reload.

python -m wlm.train --base checkpoints/base.pt \
  --manifest data/writers/ACTUAL_WRITER_FOLDER/adapt_10.jsonl \
  --method decoder --steps 200 --batch-size 4 --seed 0 \
  --output runs/pilot_decoder --device cuda

python -m wlm.train --base checkpoints/base.pt \
  --manifest data/writers/ACTUAL_WRITER_FOLDER/adapt_10.jsonl \
  --method full --steps 200 --batch-size 4 --seed 0 \
  --output runs/pilot_full --device cuda

python -m wlm.train --base checkpoints/base.pt \
  --manifest data/writers/ACTUAL_WRITER_FOLDER/adapt_10.jsonl \
  --method lora --steps 200 --batch-size 4 --seed 0 \
  --output runs/pilot_lora --device cuda

Replace the base path consistently with the phone-adapted shared model once selected. Each run saves config.json, loss.jsonl, and model.pt. Configuration records manifest/base hashes, trainable parameters, seed, elapsed training time, and CUDA peak allocated memory. The latest state is overwritten atomically every 50 updates so an interrupted job loses at most the unsaved interval.

# Continue the same run to a larger total update count:
python -m wlm.train --base checkpoints/base.pt \
  --manifest data/writers/ACTUAL_WRITER_FOLDER/adapt_10.jsonl \
  --method decoder --steps 400 --batch-size 4 --seed 0 \
  --output runs/pilot_decoder --resume runs/pilot_decoder/model.pt --device cuda

Training sanity check: first try intentionally fitting a few support examples and decode those same examples. Falling loss alone does not prove generalization, but failure to learn the tiny support set is a debugging signal. This diagnostic is not a paper test result.

Fairness: 200 steps × batch 4 gives 800 sampled presentations for every sample budget: roughly 80 presentations per example at k=10 and 8 at k=100. This controls update budget; it does not control epochs. Report that choice. If you choose budget-specific update counts, select them on development writers and predeclare them. Never adapt writer B starting from writer A's personalized model.

11. Evaluate new expressions and general retention

python -m wlm.predict evaluate --checkpoint runs/pilot_lora/model.pt \
  --manifest data/writers/ACTUAL_WRITER_FOLDER/test.jsonl \
  --output runs/pilot_lora/writer --kind writer --device cuda
python -m wlm.predict evaluate --checkpoint runs/pilot_lora/model.pt \
  --manifest data/general_2019.jsonl \
  --output runs/pilot_lora/general --kind general --device cuda

Why: support-set accuracy measures memorization; held-out writer accuracy measures useful adaptation. General-set accuracy measures interference when that personalized model is active. Switching off an isolated LoRA adapter restores the base, but the active adapter can still hurt unrelated writers.

MetricDefinition
Exact token expression matchFraction with zero token insertions, deletions, or substitutions after conservative tokenization.
Within 1 / 2 token errorsFraction with token Levenshtein distance ≤ 1 / ≤ 2; includes exactly correct predictions.
Mean edit distanceAverage minimum token edit count.
Mean normalized edit distanceAverage ED / max(reference length, prediction length, 1), between 0 and 1.
Token error rateTotal ED divided by total reference-token count; can exceed 1.
Writer-macro exact accuracyCompute each writer's exact accuracy first, then average writers equally.
Forgetting in percentage points100 × (shared-base general accuracy − adapted-model general accuracy). Positive means a drop.

Terminology matters: a LaTeX brace is a token but not a handwritten symbol. These “within 1/2” metrics are token-error tolerances, not official CROHME symbol/structure-error scores. To claim the latter, run the organizers' LaTeX-to-SymLG and Lgeval pipeline referenced by the CoMER repository. The project's own metrics should retain their explicit names. Different valid LaTeX serializations may still score differently.

Prediction files include ground truth, prediction, edit distance, writer ID, and categories for fractions, superscripts, radicals, and expressions of at least 50 tokens. Categories overlap and are descriptive, not a complete structural evaluator. Examine at least 20–30 changed cases manually, including improvements and regressions, using the image and the two predictions. Count actual symbol substitutions such as 1/l or x/× separately from lost braces and layout mistakes.

Use the same beam size throughout final comparisons. The checkpoint default is 10. --beam-size 2 --limit 5 is useful only for a quick pipeline check. Limited evaluations are marked and excluded by the analysis script. A model selected on test performance is no longer honestly evaluated by that same test.

12. Scale the study only after timing the pilot

For 20 public writers plus 3 team writers, 3 methods × 4 budgets × 3 seeds = 828 adaptation runs. Twenty writers alone gives 720. This excludes development tuning, shared domain training, base evaluations, and decoding time. If a complete run takes t minutes, 828 runs need approximately 828t/60 GPU-hours before queue delays. Measure t; do not assume a duration.

Start with one writer, then the three team writers. A useful staged plan is one seed for all methods/budgets, then three seeds on the finalized design. If resources are tight, reduce the declared cohort or scope and discuss it. Do not select only writers that improved.

python -m wlm.sweep plan --splits data/writers --base checkpoints/base.pt \
  --output runs/study/personal --jobs jobs.jsonl --steps 200 \
  --seeds 0,1,2 --general data/general_2019.jsonl
wc -l jobs.jsonl
# Read the plan before submitting. Run the first entry interactively as a pilot:
python -m wlm.sweep run --jobs jobs.jsonl --index 0 --device cuda
# Example for exactly 828 entries; substitute the actual last index printed above:
mkdir -p logs
sbatch --array=0-827%2 slurm/sweep.sbatch jobs.jsonl

%2 limits the array to two simultaneous tasks [13]. Use cluster policy and measured memory/runtime to choose concurrency and job limits. The job plan stores input hashes; changed manifests or bases cause a failure instead of silently altering the experiment. A completed training checkpoint is reused/resumed, but evaluation may rerun after a job restart.

Check disk space with df -h . and your account quota with quota -s if supported. The checked two-step checkpoints were approximately 75 MiB for full tuning, 50 MiB for decoder tuning, and 0.73 MiB for LoRA, including optimizer state. At 276 runs per method, retaining one checkpoint per run requires roughly 34 GiB before datasets, plots, and shared-domain checkpoints. Measure your files and plan storage before scaling.

Keep all base and adaptation evaluations for one shared base under the same analysis root. Put comparisons using another shared base under a different root. After the required jobs finish:

python -m pip install -r requirements-analysis.txt
python -m wlm.analyze --root runs/study --output results/study

Outputs are per_run.csv, summary.csv, forgetting.csv when available, and learning_curve.png. The script averages seeds within a writer before bootstrapping writers and computes paired gains against that writer's identical base test. Three seeds are not three independent writers. Confidence intervals with only three writers are unstable; describe them cautiously. Complete a balanced set of seeds and writers before comparing curves.

Recommended additional control: for a target writer, adapt a fresh copy to k examples from a different, genuinely unrelated writer and evaluate on the same target test. Prefer matched prompts and capture conditions. Compare this with same-writer adaptation using the same method/update budget. If both improve similarly, some benefit may reflect extra domain/task training rather than handwriting specificity. Keep controls in a separately labeled result root.

To isolate camera effects, compare the original and phone-adapted bases. To isolate augmentation, repeat a small locked development comparison with it enabled/disabled. Do not launch every possible combination before the core question is answered.

14. Write the technical approach with the right mathematics

Let x be an expression image and y = (y₁,…,yT) its LaTeX token sequence. An autoregressive recognizer models:

pθ(y|x)=∏t=1Tpθ(yt|y<t,x)

The teacher-forced training objective is negative log likelihood (cross entropy):

ℒ(θ)=−1N∑i=1N∑t=1Tilogpθ(yi,t|yi,<t,xi)

The implementation trains both left-to-right and right-to-left sequences with the official token-building utility, ignores padding in the loss, and averages over nonpadding output tokens. Thus the displayed expression gives the basic likelihood objective; the implemented loss includes both directions. Test decoding uses the official bidirectional beam search without ground-truth prefixes.

Write θ = (θencoder, θdecoder). Full tuning optimizes both groups. Decoder tuning optimizes only θdecoder. All personalization runs in this starter hold BatchNorm running statistics fixed.

For LoRA, a frozen matrix W₀ ∈ ℝdout × din becomes W₀ + (α/r)BA, with A ∈ ℝr × din, B ∈ ℝdout × r. The forward map is h = W₀z + (α/r)BAz. Only A and B learn. One matrix needs r(din+dout) trainable parameters instead of din·dout. Here r=8 and α=16, targeting six decoder FFN matrices. B starts at zero, making the adapter initially equivalent to the shared base [5].

Describe the optimizer (AdamW), clipping threshold (1.0), update budget, mini-batch sampling, trainable modules, image transforms, seed, and beam search. A theoretical-results section is optional for this empirical project. Explain design choices and limitations instead of inventing a theorem.

def interval(values, iterations=2000):
    # Resample independent writers, after averaging a writer's seeds.
    rng = random.Random(42)
    samples = sorted(mean(rng.choices(values, k=len(values))) for _ in range(iterations))
    return samples[int(.025 * iterations)], samples[min(iterations - 1, int(.975 * iterations))]

"""Manifest I/O, conservative LaTeX tokenization, and image preprocessing."""
import hashlib
import json
from pathlib import Path
import re

TOKEN_RE = re.compile(r"\\[A-Za-z]+|\\.|[^\s]")


def tokens(latex):
    text = latex.strip()
    if text.startswith("$$") and text.endswith("$$"):
        text = text[2:-2]
    elif text.startswith("$") and text.endswith("$"):
        text = text[1:-1]
    return TOKEN_RE.findall(text)


def canonical(latex):
    # Only lexical whitespace and outer math delimiters are normalized.
    return " ".join(tokens(latex))


def read_rows(path):
    path = Path(path)
    rows = []
    for line_number, line in enumerate(path.read_text().splitlines(), 1):
        if not line.strip():
            continue
        row = json.loads(line)
        for key in ("id", "image", "latex", "writer_id", "dataset", "polarity"):
            if key not in row:
                raise ValueError(f"{path}:{line_number}: missing {key}")
        if row["polarity"] not in ("dark_on_light", "light_on_dark"):
            raise ValueError(f"{path}:{line_number}: invalid polarity")
        image = Path(row["image"])
        row["image"] = str((path.parent / image).resolve() if not image.is_absolute() else image)
        rows.append(row)
    if not rows:
        raise ValueError(f"Empty manifest: {path}")
    return rows


def write_rows(path, rows):
    path = Path(path)
    path.parent.mkdir(parents=True, exist_ok=True)
    path.write_text("".join(json.dumps(r, ensure_ascii=False) + "\n" for r in rows))


def file_sha256(path):
    digest = hashlib.sha256()
    with open(path, "rb") as stream:
        for block in iter(lambda: stream.read(1024 * 1024), b""):
            digest.update(block)
    return digest.hexdigest()

    if row["polarity"] == "light_on_dark":
        image = ImageOps.invert(image)
    if augment:
        if np.random.random() < 0.35:
            image = image.filter(ImageFilter.GaussianBlur(float(np.random.uniform(0.1, 0.8))))
        pixels = np.asarray(image, dtype=np.float32)
        height, width = pixels.shape
        if np.random.random() < 0.35:
            # Mild illumination gradient; leave strokes and labels intact.
            shading = np.linspace(float(np.random.uniform(0.75, 1)), 1, width)
            pixels *= shading[None, :]
        if np.random.random() < 0.35:
            # Expand the canvas before perspective changes to avoid cropping ink.
            pixels = cv2.copyMakeBorder(pixels, 6, 6, 6, 6, cv2.BORDER_CONSTANT, value=255)
            height, width = pixels.shape
            src = np.float32([[0, 0], [width-1, 0], [width-1, height-1], [0, height-1]])
            jitter = np.random.uniform(-0.02, 0.02, (4, 2)) * [width, height]
            dst = np.float32(src + jitter)
            pixels = cv2.warpPerspective(pixels, cv2.getPerspectiveTransform(src, dst),
                                         (width, height), borderValue=255)
        image = Image.fromarray(np.uint8(np.clip(pixels, 0, 255)))
    # CoMER expects light strokes on dark background. Keep aspect ratio.
    image = ImageOps.invert(image)
    width, height = image.size
    ratio = min(1.0, 1024 / width, 256 / height)
    if ratio < 1:
        image = image.resize((max(1, round(width*ratio)), max(1, round(height*ratio))),
                             Image.Resampling.BILINEAR)
    # Padding preserves geometry even for an extreme aspect ratio.
    canvas = Image.new("L", (max(16, image.width), max(16, image.height)), 0)
    canvas.paste(image, (0, 0))
    array = np.asarray(canvas, dtype=np.float32).copy() / 255.0
    return torch.from_numpy(array)[None, :, :]


def make_batch(rows, device, augment=False, labels=True):
    import torch
    images = [image_tensor(row, augment) for row in rows]
    height, width = max(x.shape[1] for x in images), max(x.shape[2] for x in images)
    batch = torch.zeros(len(images), 1, height, width)
    mask = torch.ones(len(images), height, width, dtype=torch.bool)
    for i, image in enumerate(images):
        h, w = image.shape[-2:]
        batch[i, :, :h, :w] = image
        mask[i, :h, :w] = False
    indices = None
    if labels:
        from comer.datamodule import vocab
        indices = [vocab.words2indices(tokens(row["latex"])) for row in rows]
    return batch.to(device), mask.to(device), indices

"""Token-sequence metrics. These are not official CROHME symbol-graph metrics."""
import statistics
from .data import tokens


def edit_distance(a, b):
    previous = list(range(len(b) + 1))
    for i, left in enumerate(a, 1):
        current = [i]
        for j, right in enumerate(b, 1):
            current.append(min(current[-1] + 1, previous[j] + 1,
                               previous[j-1] + (left != right)))
        previous = current
    return previous[-1]


def score_example(truth, prediction):
    target, predicted = tokens(truth), tokens(prediction)
    distance = edit_distance(target, predicted)
    return {"ed": distance, "target_tokens": len(target), "predicted_tokens": len(predicted),
            "ned": distance / max(1, len(target), len(predicted)),
            "fraction": "\\frac" in target, "superscript": "^" in target,
            "radical": "\\sqrt" in target, "long": len(target) >= 50}


def summarize(examples):
    if not examples:
        raise ValueError("No examples to evaluate.")
    n = len(examples)
    return {"n": n, "exact": sum(e["ed"] == 0 for e in examples) / n,
            "within_1_token": sum(e["ed"] <= 1 for e in examples) / n,
            "within_2_tokens": sum(e["ed"] <= 2 for e in examples) / n,
            "mean_ed": statistics.mean(e["ed"] for e in examples),
            "mean_ned": statistics.mean(e["ned"] for e in examples),
            "token_error_rate": sum(e["ed"] for e in examples) /
                                max(1, sum(e["target_tokens"] for e in examples))}

import inspect
from pathlib import Path
import sys
import torch
from torch import nn
from torch.nn import functional as F

ROOT = Path(__file__).resolve().parents[1]
sys.path.insert(0, str(ROOT / "third_party/CoMER"))


class LoRALinear(nn.Module):
    def __init__(self, base, rank=8, alpha=16):
        super().__init__()
        self.base = base
        self.rank, self.alpha = rank, alpha
        self.lora_A = nn.Parameter(torch.empty(rank, base.in_features))
        self.lora_B = nn.Parameter(torch.zeros(base.out_features, rank))
        nn.init.kaiming_uniform_(self.lora_A, a=5**0.5)
        for parameter in base.parameters():
            parameter.requires_grad = False

    def forward(self, x):
        update = F.linear(F.linear(x, self.lora_A), self.lora_B)
        return self.base(x) + update * (self.alpha / self.rank)


def configure(model, method, rank=8, alpha=16):
    if method not in ("full", "decoder", "lora"):
        raise ValueError(method)
    for name, parameter in model.named_parameters():
        parameter.requires_grad = method == "full" or (method == "decoder" and name.startswith("decoder."))
    targets = []
    if method == "lora":
        # CoMER attention uses raw projection tensors, not standard q_proj modules.
        # Target the real, called decoder FFN Linear modules instead.
        for name, module in list(model.named_modules()):
            if name.startswith("decoder.model.layers.") and name.rsplit(".", 1)[-1] in ("linear1", "linear2"):
                if not isinstance(module, nn.Linear):
                    raise TypeError(f"Unexpected LoRA target: {name}")
                parent_name, child = name.rsplit(".", 1)
                adapter = LoRALinear(module, rank, alpha).to(device=module.weight.device,
                                                           dtype=module.weight.dtype)
                setattr(model.get_submodule(parent_name), child, adapter)
                targets.append(name)
        if len(targets) != 6:
            raise RuntimeError(f"Expected six decoder FFN targets, found {targets}")
    return targets


def training_mode(model, method):
    model.train()
    if method in ("decoder", "lora"):
        model.encoder.eval()
    # Freeze running statistics for the tiny writer datasets, including full tuning.
    # BN affine parameters still train in full mode.
    for module in model.modules():
        if isinstance(module, nn.modules.batchnorm._BatchNorm):
            module.eval()


def load_official(path):
    from comer.model.comer import CoMER
    # The legacy checkpoint has ModelCheckpoint as a dictionary key. This inert
    # allowlisted name enables restricted tensor loading without installing Lightning.
    marker = type("ModelCheckpoint", (), {})
    marker.__module__ = "pytorch_lightning.callbacks.model_checkpoint"
    with torch.serialization.safe_globals([marker]):
        raw = torch.load(path, map_location="cpu", weights_only=True)
    hparams = raw["hyper_parameters"]
    config = {name: hparams[name] for name in inspect.signature(CoMER.__init__).parameters if name != "self"}
    decode = {name: hparams[name] for name in ("beam_size", "max_len", "alpha", "early_stopping", "temperature")}
    model = CoMER(**config)
    state = {name.removeprefix("comer_model."): value for name, value in raw["state_dict"].items()
             if name.startswith("comer_model.")}
    model.load_state_dict(state, strict=True)
    return model, config, decode


def cpu_state(model):
    return {name: value.detach().cpu() for name, value in model.state_dict().items()}


def save_base(path, model, config, decode, meta):
    torch.save({"format": "wlm-1", "kind": "full", "model_config": config,
                "decode": decode, "state_dict": cpu_state(model), "meta": meta}, path)


def load_model(path, device="cpu", base_override=None):
    from comer.model.comer import CoMER
    from .data import file_sha256
    path = Path(path).resolve()
    raw = torch.load(path, map_location="cpu", weights_only=True)
    if raw.get("format") != "wlm-1":
        raise ValueError("Run bootstrap.py first; use the converted base.pt checkpoint.")
    if raw["kind"] == "lora":
        base = Path(base_override or raw["base_checkpoint"])
        if not base.is_absolute():
            base = (path.parent / base).resolve()
        if file_sha256(base) != raw["base_sha256"]:
            raise ValueError("Adapter and base hashes differ. Select the exact training base.")
        model, _ = load_model(base, "cpu")
        configure(model, "lora", raw["rank"], raw["lora_alpha"])
        expected = {n for n, p in model.named_parameters() if p.requires_grad}
        if set(raw["adapter_state"]) != expected:
            raise ValueError("Adapter keys do not match this architecture.")
        model.load_state_dict(raw["adapter_state"], strict=False)
    else:
        model = CoMER(**raw["model_config"])
        model.load_state_dict(raw["state_dict"], strict=True)
    model.to(device)
    return model, raw


def choose_device(name="auto"):
    if name == "auto":
        return torch.device("cuda" if torch.cuda.is_available() else "cpu")
    device = torch.device(name)
    if device.type == "cuda" and not torch.cuda.is_available():
        raise RuntimeError("CUDA unavailable. Request a Slurm GPU allocation or use --device cpu.")
    return device

def import_crohme(args):
    ink_root, image_root = Path(args.inkml), Path(args.images)
    images = defaultdict(list)
    for path in image_root.rglob("*"):
        if path.suffix.lower() in (".png", ".bmp", ".jpg", ".jpeg"):
            images[path.stem].append(path)
    writers = {}
    if args.writer_map:
        with open(args.writer_map, newline="") as stream:
            for row in csv.DictReader(stream):
                if row["id"] in writers:
                    raise ValueError(f"Duplicate writer-map id: {row['id']}")
                writers[row["id"]] = row["writer_id"]
    rows, rejected = [], []
    for path in sorted(ink_root.rglob("*.inkml")):
        annotations = {}
        root = ET.parse(path).getroot()
        for child in root:
            if child.tag.rsplit("}", 1)[-1] == "annotation":
                key = re.sub(r"[^a-z]", "", child.attrib.get("type", "").lower())
                annotations[key] = "".join(child.itertext()).strip()
        latex = annotations.get("truth") or annotations.get("latex")
        matches = images[path.stem]
        if not latex or len(matches) != 1:
            rejected.append({"inkml": str(path), "reason": "missing truth or non-unique image stem"})
            continue
        relative_id = path.relative_to(ink_root).as_posix()
        writer = writers.get(relative_id) or writers.get(path.stem)
        writer = writer or annotations.get("writerid") or annotations.get("writer")
        rows.append({"id": f"{args.dataset}-{relative_id}", "image": str(matches[0].resolve()),
                     "latex": latex, "writer_id": f"{args.dataset}:{writer}" if writer else None,
                     "dataset": args.dataset, "official_split": args.split, "polarity": args.polarity,
                     "inkml": str(path.resolve()), "annotations": annotations})
    write_rows(args.output, rows)
    Path(str(args.output) + ".rejected.json").write_text(json.dumps(rejected, indent=2))
    print(f"Imported {len(rows)}; rejected {len(rejected)}; "
          f"missing writer IDs: {sum(not r['writer_id'] for r in rows)}.")


def audit(args):
    dictionary = Path("third_party/CoMER/comer/datamodule/dictionary.txt")
    known = set(dictionary.read_text().splitlines())
    rows, seen_ids, seen_images, accepted = read_rows(args.manifest), set(), {}, []
    writers, unknown, problems = Counter(), Counter(), []
    for row in rows:
        reasons = []
        if row["id"] in seen_ids:
            reasons.append("duplicate id")
        seen_ids.add(row["id"])
        path = Path(row["image"])
        if not path.is_file():
            reasons.append("missing image")
        else:
            try:
                from PIL import Image
                with Image.open(path) as im:
                    im.verify()
            except Exception as error:
                reasons.append(f"unreadable image: {error}")
            digest = file_sha256(path)
            if digest in seen_images:
                reasons.append(f"duplicate image bytes: {seen_images[digest]}")
            seen_images[digest] = row["id"]
        sequence = tokens(row["latex"])
        oov = [t for t in sequence if t not in known]
        unknown.update(oov)
        if oov:
            reasons.append("out-of-vocabulary tokens")
        if not sequence or len(sequence) > 198:
            reasons.append("empty label or more than 198 tokens")
        writers[row["writer_id"] or "UNKNOWN"] += 1
        if reasons:
            problems.append({"id": row["id"], "reasons": reasons, "oov": oov})
        else:
            accepted.append(row)
    report = {"n": len(rows), "eligible_training_rows": len(accepted),
              "writer_counts": dict(writers), "unknown_tokens": dict(unknown), "problems": problems}
    Path(args.output).parent.mkdir(parents=True, exist_ok=True)
    Path(args.output).write_text(json.dumps(report, indent=2))
    if args.filtered:
        write_rows(args.filtered, accepted)
    print(json.dumps({k: v for k, v in report.items() if k != "problems"}, indent=2))
    print("Filtering is for training. Preserve every test row and report OOV coverage separately.")


def writer_splits(args):
    rows = read_rows(args.manifest)
    requested = set(args.writers.split(",")) if args.writers else None
    grouped = defaultdict(list)
    for row in rows:
        writer = row["writer_id"]
        if writer and (requested is None or writer in requested):
            grouped[writer].append(row)
    if requested and not requested.issubset(grouped):
        raise ValueError(f"Writer IDs not found: {requested - set(grouped)}")
    summary = []
    for writer, items in sorted(grouped.items()):
        # Keep one acquisition per distinct normalized formula per writer. This
        # prevents a repeated formula/photo variant entering support and test.
        unique = {}
        for row in sorted(items, key=lambda r: r["id"]):
            unique.setdefault(canonical(row["latex"]), row)
        items = list(unique.values())
        if len(items) < 100 + args.test_size:
            summary.append({"writer_id": writer, "status": "insufficient",
                            "unique_formulas": len(items), "needed": 100 + args.test_size})
            continue
        random.Random(f"{args.seed}:{writer}").shuffle(items)
        test, pool = items[:args.test_size], items[args.test_size:]
        slug = re.sub(r"[^a-zA-Z0-9_-]", "_", writer)
        # Hash suffix avoids collisions between sanitized writer IDs.
        import hashlib
        slug += "_" + hashlib.sha256(writer.encode()).hexdigest()[:8]

        for k in (10, 25, 50, 100):
            write_rows(folder / f"adapt_{k}.jsonl", pool[:k])

                        "unique_formulas": len(items), "test_size": len(test),
                        "unused": len(pool) - 100})
    out = Path(args.output)
    out.mkdir(parents=True, exist_ok=True)
    (out / "split_report.json").write_text(json.dumps(summary, indent=2))
    print(json.dumps(summary, indent=2))


def domain_split(args):

    rows = read_rows(args.manifest)
    if any(row.get("official_split") != "train" for row in rows):
        raise ValueError("Domain splits require official_split=train for every row.")
    groups = defaultdict(list)
    for row in rows:
        groups[canonical(row["latex"])].append(row)
    keys = sorted(groups)
    random.Random(args.seed).shuffle(keys)

"""Single-GPU/CPU fine-tuning with fixed update budgets and resumable checkpoints."""
import argparse
import json
import os
from pathlib import Path
import random
import time
import numpy as np
import torch
from .data import file_sha256, make_batch, read_rows, tokens
from .model import choose_device, configure, cpu_state, load_model, training_mode


def seed_all(seed):
    random.seed(seed)
    np.random.seed(seed)
    torch.manual_seed(seed)
    if torch.cuda.is_available():
        torch.cuda.manual_seed_all(seed)
    torch.backends.cudnn.benchmark = False
    torch.backends.cudnn.deterministic = True


def rng_state():
    state = np.random.get_state()
    return {"python": random.getstate(), "numpy": [state[0], state[1].tolist(), *state[2:]],
            "torch": torch.get_rng_state(),
            "cuda": torch.cuda.get_rng_state_all() if torch.cuda.is_available() else []}


def restore_rng(state):
    random.setstate(state["python"])
    n = state["numpy"]
    np.random.set_state((n[0], np.array(n[1], dtype=np.uint32), *n[2:]))
    torch.set_rng_state(state["torch"])
    if torch.cuda.is_available() and state["cuda"]:
        torch.cuda.set_rng_state_all(state["cuda"])


@torch.no_grad()
def validation_loss(model, rows, device, batch_size):
    from comer.utils.utils import ce_loss, to_bi_tgt_out
    from comer.datamodule import vocab
    model.eval()
    total, count = 0.0, 0
    for start in range(0, len(rows), batch_size):
        images, mask, labels = make_batch(rows[start:start+batch_size], device)
        target, output = to_bi_tgt_out(labels, device)
        loss = ce_loss(model(images, mask, target), output, reduction="sum")
        total += float(loss)
        count += int((output != vocab.PAD_IDX).sum())
    return total / max(1, count)


def run_training(base, manifest, output, method="decoder", steps=200, batch_size=4,
                 lr=None, seed=0, augment=False, val=None, device="auto", rank=8,
                 lora_alpha=16, save_every=50, resume=None):
    if steps < 1 or batch_size < 1 or save_every < 1:
        raise ValueError("steps, batch-size and save-every must be positive")
    device = choose_device(str(device))
    seed_all(seed)
    rows = read_rows(manifest)
    validation = read_rows(val) if val else None
    writers = {row["writer_id"] for row in rows}
    if validation is None and (len(writers) != 1 or None in writers):
        raise ValueError("Personalize on one known writer at a time. Domain training requires --val.")
    model, base_raw = load_model(base, device)
    if base_raw["kind"] == "lora":
        raise ValueError("Start each adaptation from a shared full checkpoint, not another adapter.")
    from comer.datamodule import vocab
    for row in rows + (validation or []):
        unknown = set(tokens(row["latex"])) - set(vocab.word2idx)
        if unknown or not tokens(row["latex"]) or len(tokens(row["latex"])) > 198:
            raise ValueError(f"Audit training label first: {row['id']}; unknown={unknown}")
    targets = configure(model, method, rank, lora_alpha)
    lr = lr if lr is not None else {"full": 1e-5, "decoder": 5e-5, "lora": 1e-3}[method]
    trainable = [parameter for parameter in model.parameters() if parameter.requires_grad]
    optimizer = torch.optim.AdamW(trainable, lr=lr, weight_decay=1e-4)
    folder = Path(output).resolve()
    folder.mkdir(parents=True, exist_ok=True)
    checkpoint = folder / "model.pt"
    train_config = {"base": str(Path(base).resolve()), "manifest": str(Path(manifest).resolve()),
                    "manifest_sha256": file_sha256(manifest), "method": method, "steps": steps,
                    "batch_size": batch_size, "lr": lr, "seed": seed, "augment": augment,
                    "rank": rank, "lora_alpha": lora_alpha,
                    "val": str(Path(val).resolve()) if val else None,
                    "val_sha256": file_sha256(val) if val else None}
    meta = {"method": method, "k": len(rows) if not validation else None,
            "writer_id": next(iter(writers)) if len(writers) == 1 else None,
            "seed": seed, "trainable_parameters": sum(p.numel() for p in trainable),
            "total_parameters": sum(p.numel() for p in model.parameters()), "targets": targets,
            "bn_running_statistics": "frozen", "base_sha256": file_sha256(base),
            "train_config": train_config}
    (folder / "config.json").write_text(json.dumps(meta, indent=2))
    print(json.dumps({k: v for k, v in meta.items() if k != "train_config"}, indent=2), flush=True)
    start_step, best, elapsed_before = 0, float("inf"), 0.0
    if resume:
        old_model, old = load_model(resume, device, base_override=base)
        old_config = old["meta"]["train_config"]
        for key in train_config:
            if key != "steps" and old_config.get(key) != train_config[key]:
                raise ValueError(f"Resume configuration mismatch: {key}")
        model.load_state_dict(old_model.state_dict(), strict=True)
        del old_model
        optimizer.load_state_dict(old["optimizer_state"])
        restore_rng(old["rng"])
        start_step, best = old["step"], old["best_val_loss"]
        elapsed_before = old["meta"].get("training_seconds", 0)
    if device.type == "cuda":
        torch.cuda.reset_peak_memory_stats(device)
    started = time.monotonic()

    def save(step, path):
        meta["training_seconds"] = elapsed_before + time.monotonic() - started
        meta["peak_cuda_bytes"] = torch.cuda.max_memory_allocated(device) if device.type == "cuda" else None
        raw = {"format": "wlm-1", "kind": "lora" if method == "lora" else "full",
               "model_config": base_raw["model_config"], "decode": base_raw["decode"],
               "meta": meta, "step": step, "optimizer_state": optimizer.state_dict(),
               "rng": rng_state(), "best_val_loss": best}
        if method == "lora":
            names = {name for name, p in model.named_parameters() if p.requires_grad}
            raw.update(adapter_state={name: value for name, value in cpu_state(model).items() if name in names},
                       base_checkpoint=os.path.relpath(Path(base).resolve(), Path(path).parent),
                       base_sha256=meta["base_sha256"], rank=rank, lora_alpha=lora_alpha)
        else:
            raw["state_dict"] = cpu_state(model)
        temporary = Path(str(path) + ".tmp")
        torch.save(raw, temporary)
        os.replace(temporary, path)

    log_mode = "a" if resume else "w"
    with (folder / "loss.jsonl").open(log_mode) as log:
        for step in range(start_step, steps):
            training_mode(model, method)
            # Step-indexed sampling is reproducible when a job is resumed.
            indices = random.Random(seed * 1000003 + step).choices(range(len(rows)), k=batch_size)
            examples = [rows[i] for i in indices]
            images, mask, labels = make_batch(examples, device, augment)
            from comer.utils.utils import ce_loss, to_bi_tgt_out
            target, output_ids = to_bi_tgt_out(labels, device)
            optimizer.zero_grad(set_to_none=True)
            loss = ce_loss(model(images, mask, target), output_ids)
            if not torch.isfinite(loss):
                raise RuntimeError(f"Non-finite loss at step {step + 1}")
            loss.backward()
            torch.nn.utils.clip_grad_norm_(trainable, 1.0)
            optimizer.step()
            record = {"step": step + 1, "train_loss": float(loss.detach())}
            if (step + 1) % save_every == 0 or step + 1 == steps:
                if validation:
                    score = validation_loss(model, validation, device, batch_size)
                    record["val_loss"] = score
                    if score < best:
                        best = score
                        save(step + 1, folder / "best.pt")
                save(step + 1, checkpoint)
                print(json.dumps(record), flush=True)
            log.write(json.dumps(record) + "\n")
            log.flush()
    return str(folder / "best.pt" if validation else checkpoint)

    main()
